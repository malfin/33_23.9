# Домашнее задание

## Создание раздела «Студенты» на Vue 3 и Yii2 Basic 2.0.55

---

## 1. Тема домашнего задания

Разработка CRUD-раздела **«Студенты»** в проекте Yii2 Basic 2.0.55 с использованием Vue 3 и базы данных MySQL.

---

## 2. Цель домашнего задания

Закрепить материал, изученный на практическом занятии по теме **«Использование Vue 3 с базой данных в Yii2 Basic»**.

На занятии был рассмотрен пример CRUD-раздела **«Задачи»**.
В домашнем задании необходимо самостоятельно выполнить аналогичную работу для сущности **«Студенты»**.

---

## 3. Задание

Разработать в проекте Yii2 Basic отдельный раздел **«Студенты»**, который позволяет работать со списком студентов через интерфейс на Vue 3.

Раздел должен быть доступен по адресу:

```text
http://127.0.0.1:5535/site/students
```

---

## 4. Что необходимо реализовать

Необходимо реализовать полный CRUD для студентов:

1. Вывод списка студентов.
2. Добавление нового студента.
3. Редактирование данных студента.
4. Удаление студента.
5. Изменение статуса студента: активен / неактивен.
6. Поиск студентов.
7. Фильтрация студентов по статусу.

---

## 5. Требования к базе данных

Необходимо создать таблицу:

```text
student
```

Таблица должна быть создана через миграцию Yii2.

В таблице должны быть поля:

| Поле          | Описание                          |
| ------------- | --------------------------------- |
| `id`          | Уникальный идентификатор студента |
| `last_name`   | Фамилия                           |
| `first_name`  | Имя                               |
| `middle_name` | Отчество                          |
| `group_name`  | Учебная группа                    |
| `email`       | Электронная почта                 |
| `phone`       | Телефон                           |
| `is_active`   | Статус активности студента        |
| `created_at`  | Дата создания записи              |
| `updated_at`  | Дата изменения записи             |

В таблице должно быть не менее **трёх тестовых записей**.

---

## 6. Требования к модели

Необходимо создать модель:

```text
Student
```

Модель должна быть связана с таблицей `student`.

В модели должны быть описаны:

* обязательные поля;
* правила валидации;
* подписи полей;
* автоматическое обновление даты изменения записи.

---

## 7. Требования к API-контроллеру

Необходимо создать API-контроллер для работы со студентами.

Контроллер должен выполнять следующие действия:

| Действие                   | Назначение                             |
| -------------------------- | -------------------------------------- |
| Получение списка студентов | Возвращает все записи из таблицы       |
| Получение одного студента  | Возвращает данные конкретного студента |
| Добавление студента        | Создаёт новую запись                   |
| Редактирование студента    | Изменяет данные существующего студента |
| Удаление студента          | Удаляет запись                         |
| Изменение статуса          | Меняет активность студента             |

Ответы контроллера должны возвращаться в формате JSON.

---

## 8. Требования к странице students.php

Необходимо создать страницу:

```text
views/site/students.php
```

На странице должен быть реализован интерфейс на Vue 3.

Страница должна содержать:

* заголовок раздела;
* форму добавления студента;
* форму редактирования студента;
* таблицу со списком студентов;
* поле поиска;
* фильтр по статусу;
* кнопки управления записями;
* сообщения об ошибках;
* сообщения об успешных действиях.

---

## 9. Требования к форме студента

Форма должна содержать следующие поля:

| Поле     | Обязательное       |
| -------- | ------------------ |
| Фамилия  | Да                 |
| Имя      | Да                 |
| Отчество | Нет                |
| Группа   | Да                 |
| Email    | Нет                |
| Телефон  | Нет                |
| Активен  | При редактировании |

При добавлении нового студента статус активности должен устанавливаться автоматически.

---

## 10. Требования к таблице студентов

В таблице необходимо вывести:

| Столбец  | Содержание              |
| -------- | ----------------------- |
| ID       | Номер записи            |
| ФИО      | Фамилия, имя и отчество |
| Группа   | Учебная группа          |
| Email    | Электронная почта       |
| Телефон  | Телефон                 |
| Статус   | Активен / Неактивен     |
| Действия | Кнопки управления       |

В столбце **Действия** должны быть кнопки:

* изменить;
* изменить статус;
* удалить.

---

## 11. Требования к поиску

На странице должен быть реализован поиск студентов.

Поиск должен работать минимум по следующим полям:

* фамилия;
* имя;
* отчество;
* группа;
* email;
* телефон.

После ввода поискового запроса на странице должны отображаться только подходящие записи.

---

## 12. Требования к фильтрации

На странице должна быть реализована фильтрация по статусу:

* все студенты;
* активные студенты;
* неактивные студенты.

---

## 13. Что должно получиться в результате

В результате выполнения домашнего задания должен получиться рабочий раздел **«Студенты»**, в котором можно:

1. Открыть страницу студентов.

3. Добавить нового студента.

6. Изменить статус студента.
